# Мастерская улыбок / Mastersmile Surgut

Локальная демо-версия одностраничного сайта стоматологии. Откройте `index.html` в браузере или запустите любой локальный HTTP-сервер из этой папки.

## Источники данных

- Яндекс Карты: карточка организации из запроса заказчика.
- 2ГИС: адрес, рейтинг, число оценок, фотографии и отзывы.
- Doctu: перечень подтверждённых направлений стоматологии.

Перед публикацией владелец должен подтвердить режим работы, юридические сведения, лицензию, актуальный состав врачей и согласовать использование фотографий.

## Обновление позиционирования

Главная страница обновлена по заданию: «Свой стоматолог для всей семьи», знакомство с доктором, индивидуальный подход, акцент на лечении и протезировании, бесплатная консультация. Существующие фотографии, отзывы, карта и способы записи сохранены. Кнопки записи открывают звонок в клинику.

### Данные для завершения перед публикацией

- Подтвердить фотографии и данные врачей, перенесённые из asamasite/mastersmile: Тимур Гаджиев и Аскерхан Багаутдинович. Получить полное ФИО второго врача, образование, документы о квалификации и подтверждение опыта в протезировании.
- Получить точный адрес Telegram. После этого добавить ссылку в шапку, мобильное меню и контакты. Сейчас ссылка отсутствует, чтобы не направлять пациентов на неподтверждённый аккаунт.
- Получить утверждённый прайс: название процедуры, состав и стоимость. На странице указана только предоставленная в задании бесплатная консультация; цены остальных услуг не придуманы.
- Подтвердить объём бесплатной консультации и условия оплаты диагностики.
- Подтвердить возможность приёма детей, перечень ортопедических услуг и остальные направления по действующей лицензии; внести юридические реквизиты и сведения о лицензии.
- Согласовать акцию «Приведи друга»: получатель скидки, процедуры, ограничения и срок действия. До согласования акция на странице не размещена.

Проверено автоматически: корректная вложенность HTML, уникальность идентификаторов, цели якорных ссылок, наличие локальных изображений, единственный H1 и синтаксис JavaScript (`node --check`). Публикация не выполнялась. Результаты последующей визуальной проверки приведены ниже.


## Перенос решений из mastersmile

Источник: https://github.com/asamasite/mastersmile (главная страница и фотографии врачей из ветки main), версия https://mastersmile.asama.site/.

Перенесены и адаптированы к текущей палитре и Golos Text:

- Две карточки врачей с портретами, специализациями и записью по телефону.
- Расширение направлений: хирургия, ортодонтия, диагностика, эстетика; основные лечение и протезирование остаются первыми и выделены цветом.
- Четыре этапа первого визита, шесть раскрывающихся ответов на частые вопросы.
- Часы работы, парковка, вход с улицы Губкина, способы оплаты и Wi-Fi.
- Три отзыва из версии-источника со ссылкой на Яндекс Карты; отзывы 2ГИС сохранены.
- Постоянная мобильная кнопка записи, переключение фотографий галереи, клавиши стрелок и Escape, возврат фокуса.

Перед публикацией подтвердить у владельца перенесённые сведения: актуальные часы работы, способы оплаты, доступность направлений и диагностики, квалификацию врачей, подлинность и разрешение на использование портретов, тексты отзывов. Эти данные перенесены из предоставленной версии, а не независимо проверены по документам. Не добавлены отсутствующие цены, условия акции и Telegram. Формулировки «Открыто» и «Данные Росздравнадзора» без проверки не перенесены.

Проверка: HTML и JavaScript прошли статические проверки. В браузере проверены десктопная версия и ширина 390 px, навигация, мобильное меню, FAQ, галерея и закрытие Escape. Горизонтального переполнения на мобильной ширине и ошибок JavaScript не обнаружено. Визуально проверены первый экран и блок врачей. Сайт не опубликован.


## Переработка дизайна: зелёная палитра и дуги

По пожеланию заказчика сохранены зелёный цвет и полукруглые нижние края секций. Вёрстка переработана целиком: арочное изображение на первом экране, компактные парные блоки врачей, два основных направления и четыре дополнительных, единый блок первого визита и подхода. Повторяющийся блок этапов удалён, дополнительные отзывы 2ГИС свёрнуты в раскрываемый архив. Содержимое доступно сразу, искусственная загрузка и анимации появления удалены.

Шрифтовая семья — Golos Text. Основные стили собраны в styles.css; additions.css больше не используется. Палитра: тёмно-зелёный #174c3e, светло-зелёный #e5ede1, светлый фон #faf9f3, мягкий акцент #e2ecc5.

Проверена новая композиция на десктопе 1440 px и телефоне 390 px. Проверены меню, раскрытие FAQ, архив отзывов и переключение слайдера. Статические проверки HTML, якорей и синтаксиса JavaScript пройдены. Изменения не опубликованы.
